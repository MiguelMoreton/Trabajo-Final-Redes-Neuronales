## 📌 Description

This repository contains the development of our **Final Project for the Neural Networks course**, focused on the creation, training, and comparison of different Deep Learning models for a **multiclass image classification** problem.

Throughout the project, different architectures and training techniques were tested, starting with **Fully Connected** networks and evolving towards convolutional models based on **ResNet18**, together with hyperparameter optimization using **Optuna**.

The final goal was to train a model capable of generating predictions on a test set and saving them in `.npz` format, so that the professor could later evaluate them using the real labels.

This project received a final grade of **10/10** and was part of a class competition, where our team achieved the best result in the class.

---

## 🚀 Project Objectives

- Implement neural network models with **PyTorch**.
- Compare different architectures.
- Apply data preprocessing and transformation techniques.
- Improve training using optimizers and schedulers.
- Use **Optuna** for hyperparameter search.
- Save the best trained model.
- Generate final predictions on test data.

## ▶️ Execution

To follow the complete development of the project, it is recommended to review the notebooks in the following order:

```text
1. Fully_Connected.ipynb
2. Fully_Connected_torchTransforms.ipynb
3. Fully_Connected_torchTransformsAdamyPlateau.ipynb
4. Fully_Connected_torchTransformsAdamyPlateauyOptuna.ipynb
5. ResNet18_1.0.ipynb
6. ResNet18_2.0.ipynb
7. ResNet18_3.0.ipynb
8. ResNet18_4.0.ipynb
9. ResNet18_4.0_optuna.ipynb
10. Prediccion_Y_pred_GELU_manual.ipynb
```

To generate the final predictions:

1. Make sure `Best_model.pth` and `X_test.npz` are in the root directory.
2. Run the notebook `Prediccion_Y_pred_GELU_manual.ipynb`.
3. The file `Y_pred.npz` will be generated.

## 📈 Final Prediction

The final predictions are saved as:

```text
Y_pred.npz
```

The file contains a matrix with the probabilities assigned by the model to each class.

It can be loaded with:

```python
import numpy as np

data = np.load("Y_pred.npz")
Y = data["Y"]

print(Y.shape)
```
